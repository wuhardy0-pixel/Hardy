## How to resume this project

1.  Read PRD.md (product + architecture), then this file.
2.  Backend: `./run_backend.sh` (Flask :5000). Needs `.env` with
    `OPENAI_API_KEY` and `OPENAI_MODEL` (currently `gpt-5.6-terra`).
3.  SIMPLEST START: double-click "Start BookKeep.command" (also
    linked on the Desktop) — starts backend + tunnel and opens
    welcome_bookkeep.html (big Open button for the Mac, QR code +
    link for phones; page regenerated by make_welcome.py each start).
    "Stop BookKeep.command" shuts it all down. Logs:
    /tmp/bookkeep_server.log, /tmp/bookkeep_tunnel.log.
    Details: the Flask backend now serves the frontend too — open
    http://127.0.0.1:5000 directly (index/app.js/style.css whitelist;
    .env and the DB are blocked). Public HTTPS URL:
    `cloudflared tunnel --url http://127.0.0.1:5000 --no-autoupdate`
    (brew-installed; prints a random *.trycloudflare.com URL — NEW
    URL on every restart, don't share beyond family; a stable named
    tunnel needs a Cloudflare account). backendBase() in app.js makes
    the app use its own origin for the API when served over :5000 or
    HTTPS, so phones work end-to-end. `python3 -m http.server 8000`
    still works for local dev (test harnesses use it). LLM mode:
    Settings → Agent mode → "LLM API" (endpoint/model fields blank =
    use backend).
4.  Tests: `node parser_tests.js` (extracts parser fns from app.js —
    30 cases) and `node browser_smoke_test.js` (headless-Chrome UI
    suite, now saved in-repo; needs `npm install` once for
    playwright-core + installed Google Chrome; serves the app itself
    on a throwaway port).
5.  Wipe data: `wipe_browser.html` (localStorage) and
    `python3 wipe_backend.py` (SQLite).
