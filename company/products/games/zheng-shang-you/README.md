# 争上游 Zheng Shang You

Status: **live** at play.hardywu.com/play/zsy (sign-in at logzsy.hardywu.com).

The family card game, "jun shong yo", for a phone screen. One file, `index.html`. 2–5 seats, each a named person or a computer (Grandma, Uncle, Cousin, Auntie). Several people can play on one phone (a cover screen hides the cards while the phone is passed) or each on their own phone in an online room (create → share the 4-letter code or link → join; the server runs the table).

House rules (Barbara's family version, 2026-10-14):
- Ranks 3 < 4 … < 10 < J < Q < K < A < 2 < small joker < big joker. 54-card deck, dealt out fully.
- Singles only compete with singles, pairs only with pairs. No straights.
- Three of a kind is a bomb (beats any single or pair); four of a kind is a bigger bomb; the two jokers together beat everything.
- Can't beat the pile? Pass. When everyone else has passed, the last player leads again (or the next player if they finished).
- First out is 上游; the standings show everyone's finishing place. The champion leads the next game.

Controls: tap cards to select, Play / Pass / Hint. P or Esc pauses. 💬 feedback button.
Sign-in: no sign-in code inside the game; the server's sign-in gate wraps /play/zsy.
