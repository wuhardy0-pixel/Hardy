# BookKeep

Status: **live** at bookkeep.hardywu.com (also books.hardywu.com).

Speak-it, snap-it bookkeeping: transactions, journal, ledger, evidence, reports, an AI agent, and for Hardy an Orders tab with the print queue. Front-end only: `index.html`, `app.js`, `style.css`. Books live in the browser and are backed up to corporate per login (`/api/backup`); the AI agent, evidence and audit log are in corporate too.

- Run locally: start corporate, open http://127.0.0.1:5000/ (local = no sign-in, owner view).
- Tests: `node browser_smoke_test.js` (needs Chrome; `npm install` once) and `node parser_tests.js`. See `TESTING.md`.
- `PRD.md` what it must do · `TASKS.md` history and next · `FEEDBACK.md` what users said · `docs/` the older version notes (V7–V14), the agent design, fix notes.
- `welcome_bookkeep.html` is generated by `make_welcome.py` (phone link page).
