# prints — 3D-printed goods for sale

Status: **live** (sold through the shop at shop.hardywu.com).

One folder per item in `items/` (moved from `Hardy's 3D Business/assets/products`): model files, print settings, photos and the write-up the shop shows. `items/README.md` and `items/shop-info.md` describe the catalogue; `design/` holds design sources (e.g. Lunchbox Lid Maker), `tools/` the helper scripts.

The shop reads its product list from `site/shop/data/catalog.json` and product images from `site/shop/public/products/`; when an item here changes, update those.

This is one product line for now. Split into lines (garden tools, handyman tools, robot kits) when there are enough items to matter.
